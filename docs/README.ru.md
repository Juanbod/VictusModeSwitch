# Victus Mode Switch

[English README](../README.md)

Лёгкая программа для Windows 11, которая заменяет базовое переключение режимов OMEN Gaming Hub на поддерживаемом HP Victus.

> [!CAUTION]
> Проект разработан при помощи ИИ и проверен только на одном ноутбуке. Программа обращается к недокументированному интерфейсу HP BIOS. Установка и использование выполняются полностью на ваш страх и риск. Перед установкой прочитайте [полный отказ от ответственности](../DISCLAIMER.md).

![Основная страница настроек](images/settings-general.jpg)

## Поддерживаемый ноутбук

- HP Victus 15-fa0020ua;
- системная плата `8A4F`;
- HP Thermal Policy `V0`.

При несовпадении платы или Thermal Policy запись в BIOS блокируется. Совместимость с другими Victus пока не заявлена.

## Управление

| Действие | Результат |
|---|---|
| Одно нажатие ромбика | Стандартный ↔ Performance |
| Два быстрых нажатия | Max Fan вкл. / выкл. |
| Три быстрых нажатия | Eco |
| Правая кнопка по значку в трее | Выбор режима без всплывающей плашки |
| Двойной щелчок по значку | Настройки |

Удержание кнопки прошивка этого ноутбука не позволяет отличить от короткого нажатия: приходит только один WMI-импульс. Поэтому для Eco используется тройное нажатие.

## Установка

1. Скачайте [`VictusModeSwitch-Setup.exe`](https://github.com/Juanbod/VictusModeSwitch/releases/latest/download/VictusModeSwitch-Setup.exe) и файл [`VictusModeSwitch-Setup.exe.sha256`](https://github.com/Juanbod/VictusModeSwitch/releases/latest/download/VictusModeSwitch-Setup.exe.sha256).
2. Сравните SHA-256:

   ```powershell
   (Get-FileHash .\VictusModeSwitch-Setup.exe -Algorithm SHA256).Hash
   Get-Content .\VictusModeSwitch-Setup.exe.sha256
   ```

3. Запустите установщик и прочитайте предупреждение.
4. Один раз подтвердите UAC: установщик проверит ноутбук, поместит защищённый BIOS-брокер в `Program Files` и создаст для него короткую задачу с повышенными правами.

Установщик пока **не подписан Authenticode-сертификатом**, поэтому Windows может показать неизвестного издателя. SHA-256 проверяет целостность файла, но не заменяет цифровую подпись издателя.

Опциональная галочка установщика отключает фоновые помощники OMEN Gaming Hub. Сам Gaming Hub не удаляется, служба HP Omen HSA остаётся включённой, а исходные состояния восстанавливаются при удалении программы.

## Режимы

- **Eco:** стандартный профиль BIOS, отключение Max Fan при входе и, при включённой настройке Windows, экономичный профиль с выбранными пределами процессора.
- **Стандартный:** обычный профиль BIOS и восстановление исходных параметров питания Windows.
- **Performance:** производительный профиль BIOS и опциональная настройка Windows на максимальную скорость.
- **Max Fan:** независимый режим максимальных оборотов вентиляторов.

## Автообновление и приватность

Программа не содержит телеметрии и аналитики. При включённой проверке обновлений она обращается только к публичному GitHub Releases API, не чаще одного раза в сутки. Установка никогда не начинается без нажатия пользователя. Перед запуском setup SHA-256 проверяется дважды.

В простое приложение ждёт событие HP WMI и на проверенном ноутбуке использует около 15-25 МБ приватной памяти при практически нулевой загрузке CPU.

Повышенный BIOS-брокер хранится в `Program Files`, принимает только фиксированные команды режимов и запускается скрыто, без окна PowerShell.

## Удаление

Откройте **Параметры > Приложения > Установленные приложения > Victus Mode Switch > Удалить**. Деинсталлятор включает Стандартный режим, выключает Max Fan, восстанавливает сохранённые параметры Windows и OMEN, затем удаляет запись автозапуска и повышенную BIOS-задачу.

Настройки и журнал остаются в `%LOCALAPPDATA%\VictusModeSwitch`, чтобы их можно было сохранить между переустановками.
