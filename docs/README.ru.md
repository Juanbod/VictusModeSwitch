# Victus Mode Switch

[English README](../README.md)

Лёгкая программа для Windows 11, которая заменяет базовое переключение режимов OMEN Gaming Hub на поддерживаемом HP Victus.

> [!CAUTION]
> Проект разработан при помощи ИИ и проверен только на одном ноутбуке. Программа обращается к недокументированному интерфейсу HP BIOS. Установка и использование выполняются полностью на ваш страх и риск. Перед установкой прочитайте [полный отказ от ответственности](../DISCLAIMER.md).

![Основная страница настроек](images/settings-general.png)

## Поддерживаемый ноутбук

- HP Victus 15-fa0020ua;
- системная плата `8A4F`;
- HP Thermal Policy `V0`.

При несовпадении платы или Thermal Policy запись в BIOS блокируется. Совместимость с другими Victus пока не заявлена.

## Управление

| Действие | Результат |
|---|---|
| Одно нажатие ромбика | Стандартный ↔ Performance |
| Два быстрых нажатия | Max Fan вкл. / выкл. |
| Три быстрых нажатия | Eco |
| Назначенная комбинация клавиш | Повторяет одиночное, двойное и тройное нажатие ромбика |
| Правая кнопка по значку в трее | Выбор режима без всплывающей плашки |
| Двойной щелчок по значку | Настройки |

В текущей раскладке для Eco используется тройное нажатие. HP WMI передаёт только один импульс без события отпускания, а отдельный клавиатурный канал отвечает за надёжное распознавание нажатий сразу после входа в Windows.

Чтобы назначить клавиатурную альтернативу, откройте **Настройки > Основное**, нажмите **Не назначено** и введите сочетание с `Ctrl`, `Alt`, `Shift` или `Win`. `Esc` отменяет запись, а кнопка удаления либо `Backspace`/`Delete` без модификаторов очищает хоткей. По умолчанию комбинация не назначена.

Переключатель **Запускать вместе с Windows** на той же странице сразу добавляет или удаляет автозапуск для текущего пользователя. Выбор сохраняется при обновлении и не требует UAC.

## Установка

1. Скачайте [`VictusModeSwitch-Setup.exe`](https://github.com/Juanbod/VictusModeSwitch/releases/latest/download/VictusModeSwitch-Setup.exe) и файл [`VictusModeSwitch-Setup.exe.sha256`](https://github.com/Juanbod/VictusModeSwitch/releases/latest/download/VictusModeSwitch-Setup.exe.sha256).
2. Сравните SHA-256:

   ```powershell
   (Get-FileHash .\VictusModeSwitch-Setup.exe -Algorithm SHA256).Hash
   Get-Content .\VictusModeSwitch-Setup.exe.sha256
   ```

3. Запустите установщик и прочитайте предупреждение.
4. Один раз подтвердите UAC: установщик проверит ноутбук, поместит защищённый BIOS-брокер в `Program Files` и создаст для него короткую задачу с повышенными правами.

Установщик пока **не подписан Authenticode-сертификатом**, поэтому Windows может показать неизвестного издателя. SHA-256 проверяет целостность файла, но не заменяет цифровую подпись издателя.

Опциональная галочка установщика отключает фоновые помощники OMEN Gaming Hub. Сам Gaming Hub не удаляется, служба HP Omen HSA остаётся включённой, а исходные состояния восстанавливаются при удалении программы.

## Минимум программ HP

Victus Mode Switch напрямую использует HP WMI-интерфейс BIOS и событие кнопки-ромбика. OMEN Gaming Hub, HP Support Assistant и пользовательские HSA-службы программа не вызывает.

Безопасный консервативный минимум для проверенного ноутбука:

- **HP Application Driver** (`ACPI\HPIC0003`);
- **HP Omen Driver** (`ACPI\HPIC0004`);
- драйвер NVIDIA, только если нужен дополнительный лимит 60 FPS.

Если другие программы HP не используются, самой Victus Mode Switch не нужны OMEN Gaming Hub, HP Support Solutions Framework, HP Insights/Touchpoint Analytics и службы `HPAppHelperCap`, `HPDiagsCap`, `HPNetworkCap`, `HPOmenCap`, `HPSysInfoCap`. Во время одного замера пять запущенных помощников вместе занимали около 206 МБ приватной памяти. Их удаление может отключить диагностику HP Support Assistant и другие функции HP, Windows Update может установить их снова. Драйверы чипсета, ACPI, клавиатуры и видеокарты удалять вместе с ними не следует.

Опция **Приостанавливать лишние службы HP** останавливает только эти пять HSA-служб, локально проверяет их состояние раз в 15 секунд и при выходе восстанавливает только те, которые работали до включения опции. Список восстановления сохраняется на случай сбоя, обновления или удаления программы. Аппаратные драйверы HP остаются активными.

## Режимы

- **Eco:** стандартный профиль BIOS, отключение Max Fan при входе и, по отдельным настройкам, 60 Гц для встроенного экрана, глобальный лимит NVIDIA 60 FPS и отключение Turbo Boost. Все три настройки изначально выключены.
- **Стандартный:** обычный профиль BIOS и восстановление сохранённых параметров питания Windows, частоты экрана, лимита NVIDIA и Turbo Boost.
- **Performance:** производительный профиль BIOS, восстановление Eco-ограничений и опциональная настройка Windows на максимальную скорость.
- **Max Fan:** независимый режим максимальных оборотов вентиляторов.

## Автообновление и приватность

Программа не содержит телеметрии и аналитики. При включённой проверке обновлений она обращается только к публичному GitHub Releases API, не чаще одного раза в сутки. При подавлении служб выполняется только локальная проверка их состояния раз в 15 секунд. Установка никогда не начинается без нажатия пользователя. Перед запуском setup SHA-256 проверяется дважды.

В простое приложение ждёт событие HP WMI и на проверенном ноутбуке использует около 15-25 МБ приватной памяти при практически нулевой загрузке CPU.

Повышенный BIOS-брокер хранится в `Program Files`, принимает только фиксированные команды режимов и ограниченный список из пяти HP-служб, запускается скрыто, без окна PowerShell.

## Исследование протокола BIOS

Подробно задокументированы [путь OMEN Gaming Hub через HSA/RPC, транспорт HP WMI, карта команд и возможности платы `8A4F`](hp-bios-protocol.ru.md). В документе отдельно отмечены реально проверенные операции, кандидаты только для чтения и опасные команды, которые приложение намеренно не использует. Есть и [английская версия](hp-bios-protocol.md).

Безопасный отчет о железе, WMI-схеме, версиях OMEN/HSA и реестровом кэше можно получить без единого вызова BIOS-метода:

```powershell
.\scripts\Inspect-HpBiosInterface.ps1 -OutputPath .\artifacts\hp-bios-interface.json
```

## Удаление

Откройте **Параметры > Приложения > Установленные приложения > Victus Mode Switch > Удалить**. Деинсталлятор включает Стандартный режим, выключает Max Fan, восстанавливает приостановленные HP-службы, сохранённые параметры питания Windows, частоту экрана, лимит NVIDIA, Turbo Boost и настройки OMEN, затем удаляет запись автозапуска и повышенную BIOS-задачу.

Настройки и журнал остаются в `%LOCALAPPDATA%\VictusModeSwitch`, чтобы их можно было сохранить между переустановками.
